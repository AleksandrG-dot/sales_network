# Сеть по продаже электроники
Веб приложение сети по продаже электроники с API-интерфейсом и админ-панелью.   
Позволяет регистрировать звенья цепи трёх типов: завод, розничная сеть и индивидуальный предприниматель.  
Каждое звено может содержать несколько контактных данных и несколько продуктов, но только одного поставщика.
Каждое звено имеет уровень иерархии. Заводу требуется устанавливать уровень иерархии 0. Дальнейший подсчет уровня 
иерархии звена осуществляется в автоматическом режиме в зависимости от выбранного поставщика.  
Для работы с сервисом требуется авторизация пользователя.  
Создано на Django REST Framework и БД PostgreSQL.

## Локальный запуск

1. Клонируйте репозиторий из GitHub  
`git clone https://github.com/AleksandrG-dot/sales_network.git`
2. Создайте базу данных в PostgreSQL
3. Создайте файл `.env` и заполните по примеру `.env.example`
4. Примените миграции командой  
`python manage.py migrate`
5. Наполните данными или создайте суперпользователя (команды приведены ниже)
6. Запустите проект:  
`python manage.py runserver`
7. Сервис доступен по адресу `http://127.0.0.1:8000/` или `http://localhost:8000/`

## Наполнение данными
`python manage.py add_users`  - добавление пользователей (суперпользователь, User1, User2  Пароль: 123qwe)  
`python manage.py add_data` - добавление данных о продуктах, контактах и узлах сети


## Создание суперпользователя
`python manage.py createadmin` - создание суперпользователя (username, email, password из .env)

## Описание
Пользователи - это менеджеры, которые управляют всеми ресурсами приложения.
Доступ к API имеют только авторизованные пользователи со статусом is_active.  
Для тестовых данных (из наполнения данными) можно использовать `Token d47f613bf7a05ffc937008b08fa91e246c2b95ed`  
Для этого необходимо добавить в Heders запроса ключ Authorization со значением этого токена. 

Для создания звена цепи необходимо сначала создать контакты и продукты для этого звена.

Сети бывают трех типов (поле "type"):
- 'factory' = 'Завод',
- 'retail' = 'Розничная сеть'
- 'entrepreneur' = 'ИП'  (Индивидуальный предприниматель)

### Работа приложения через админ-панель  
`http://localhost:8000/admin/`  
На странице "Продукты" реализовано:
- поиск по полям "Название" и "Модель"
- фильтр по Дате выхода на рынок 

На странице "Контакты" реализовано:
- поиск по полю "E-mail"
- фильтры по Стране и Городу

На странице "Звенья сети" реализовано:
- поиск по полю "Название" и "E-mail контакта"
- фильтры по Городу, Типу, Дате создания звена  
- admin actions для очистки долга перед поставщиком (поле "Действие" -> "Очистить задолжность")
- ссылки на поставщика и на контакт
- поле "КОЛ-ВО ПРОД." с количеством продуктов в данном звене

### Документация по API:  
`http://localhost:8000/swagger/`  
`http://localhost:8000/redoc/`

### Работа с пользователями 
CRUD для пользователей:  
`http://localhost:8000/users/user/`  
*Вновь созданные пользователи (через POST-запрос) имеют статус is_active=False (не активен).*  
*Активным пользователя может сделать только другой пользователь (через запросы PUT или PATCH), либо суперпользователь через админ-панель.*

Получение токена пользователя (авторизация)  
`http://localhost:8000/users/login/`

### Работа с контактами 
CRUD для контактов:  
`http://localhost:8000/api/contacts/`  

Поиск контактов (по полям "country", "city", "email")  
`http://localhost:8000/api/contacts?search=<текст_поиска>`

### Работа с продуктами 
CRUD для продуктов:  
`http://localhost:8000/api/products/`  

Поиск продуктов (по полям "name", "model")  
`http://localhost:8000/api/products?search=<текст_поиска>`

### Работа со звеньями цепи 
CRUD для звеньев цепи:  
`http://localhost:8000/api/network-nodes/`  
*Поля level, created_at, debt не редактируемы.*  
*Поле debt возможно указать при создании звена цепи.*

Фильтрация объектов по определенной стране:  
`http://localhost:8000/api/network-nodes/?contacts__country=RU`

Сортировка по полям "id", "name", "level", "debt", "created_at".  
Примеры:  
`http://localhost:8000/api/network-nodes/?ordering=id`    # по возрастанию (A-Z, 1-9)  
`http://localhost:8000/api/network-nodes/?ordering=-id`   # по убыванию (Z-A, 9-1)
